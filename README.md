# DEMO_PEPINA

Demo interactiva de la plataforma de atención al cliente para Pepina Pastel: una bandeja única para email, WhatsApp, Instagram y Facebook.

- Lista de tickets con estados (abierto, pendiente, pospuesto, resuelto) y filtros por canal.
- Tickets de ejemplo de email y WhatsApp, más Instagram y Facebook.
- Crear un ticket nuevo, responder, dejar notas internas, usar respuestas guardadas y simular la respuesta del cliente.

Todo funciona en el navegador con datos de ejemplo: no se envía ningún mensaje real. Es un único archivo, `index.html`, publicado con GitHub Pages.
